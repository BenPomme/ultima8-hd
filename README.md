# Ultima VIII: Pagan — Desktop Remake (Fan Project)

Play in a desktop browser: **https://benpomme.github.io/ultima8-hd/**

**Requirements**
A desktop browser (Chrome, Edge or Firefox, current versions) with a keyboard and mouse. Mobile and touch devices are not supported. Nothing needs to be installed or imported. The game, including its assets and HD art packs, is hosted and ready to play when you open the page.

**Features**
- Ready-to-play hosted Ultima VIII remake. Open the link and play, with no file import or setup.
- HD UI and art. 2x scaling by default, with an optional 4x mode.
- Smooth walking at a tuned movement pace. The pace is adjusted for this remake and is not the original game's timing.
- Basic combat: the Avatar can attack and defeat a target.
- LLM-driven NPC conversation with per-NPC memory. NPCs can remember what you tell them across reloads. Use the **"Forget this NPC"** button to clear an NPC's memory of you.
- One NPC (Devon) has been verified end-to-end. Other NPCs use the same natural-language system (5 character cards plus generic profiles) but are not yet individually verified.

AI dialogue is served through a project-operated backend. Players do not need an API key.

## Known limitations
- Combat uses the original baseline. Only basic attack-to-defeat is verified.
- AI chat for other characters and text-to-speech are not verified.
- AI replies may occasionally be slow or unavailable; the original game is unaffected.
